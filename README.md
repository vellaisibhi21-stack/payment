# LaneSync Java (Gradle) Starter

Minimal Java 17 + Gradle + JUnit 5 project scaffolded by LaneSync.

## Prerequisites

- Java 17+

## Run tests

```bash
./gradlew test
```

The Gradle wrapper (`gradlew`, `gradlew.bat`, `gradle/wrapper/`) is included so CI and local runs do not need a global Gradle install.

## Coverage report

Generated at `build/reports/jacoco/test/html/index.html` after `./gradlew test`.
